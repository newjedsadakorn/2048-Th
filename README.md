# 2048

เกม 2048 แบบดั้งเดิม เขียนด้วย HTML CSS และ JavaScript ล้วน ไม่มี framework ไม่มี dependency ไม่ต้อง build ก็รันได้

เล่นได้ทั้งบนมือถือและคอมพิวเตอร์ ออกแบบมาสำหรับจอแนวตั้ง

---

## มีอะไรบ้าง

**โหมดเล่น**

- กระดาน 3×3, 4×4 และ 5×5
- ท้าทายประจำวัน กระดานถูกสุ่มจากวันที่ ทุกคนที่เล่นวันเดียวกันจะเจอลำดับการเกิดช่องเหมือนกันทุกประการ จึงเทียบฝีมือกันได้จริง
- ย้อนกลับได้หนึ่งตา ปิดได้ในตั้งค่า

**ระบบธีม**

ปรับแยกกันได้สี่อย่าง ผสมกันได้ 6 × 11 × 6 × 3 แบบ

- พื้นหลัง 6 ชุด บวกโหมดตามระบบที่สลับสว่างมืดตามเครื่อง
- สีช่องตัวเลข 11 ชุด (5 ชุดเปิดตั้งแต่ต้น อีก 6 ชุดปลดล็อกจากการเช็คอิน)
- ฟอนต์ตัวเลข 6 แบบ โหลดเฉพาะตัวที่เลือกใช้
- ความโค้ง 3 ระดับ ซึ่งคุมมุมโค้งและระยะขอบทั้งแอปพร้อมกัน

สีปุ่มและสีไฮไลต์ทั้งแอปดึงมาจากชุดสีช่องอัตโนมัติ จึงไม่มีทางผสมออกมาแล้วสีตีกัน

**เช็คอินรายเดือน**

- ปฏิทินของเดือนปัจจุบัน แสดงวันที่เช็คแล้ว วันที่พลาด และวันที่ยังมาไม่ถึง แยกน้ำหนักสีคนละระดับ
- นับวันต่อเนื่อง วันที่อยู่ในช่วงต่อเนื่องจะถูกไฮไลต์เป็นแถบในปฏิทิน
- ของรางวัลนับจากจำนวนวันที่เช็คในเดือนนั้น ที่ 3, 8, 15 และ 22 วัน
- ชุดของรางวัลหมุนใหม่ทุกวันที่ 1 เก็บไม่ครบภายในเดือนก็ต้องรอรอบถัดไป ของที่ได้แล้วเก็บถาวร ไม่ริบคืน
- ของรางวัลเป็นของตกแต่งล้วนๆ ไม่มีอะไรที่ทำให้เล่นได้เปรียบ

**อื่นๆ**

- กระดานคะแนน แยกตามโหมดและตามท้าทายประจำวัน
- สถิติสะสมและประวัติเกมล่าสุด 12 เกม
- ติดตั้งเป็นแอปบนมือถือได้ เล่นออฟไลน์ได้
- รองรับ `prefers-reduced-motion` สำหรับคนที่ไม่ชอบภาพเคลื่อนไหว

## รันบนเครื่องตัวเอง

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย แต่ service worker กับการติดตั้งเป็นแอปจะไม่ทำงานเมื่อเปิดแบบ `file://` ถ้าอยากทดสอบส่วนนั้นด้วยให้เสิร์ฟผ่าน http

```bash
# วิธีไหนก็ได้ที่ถนัด
python3 -m http.server 8000
npx serve .
```

แล้วเปิด `http://localhost:8000`

## ขึ้น GitHub Pages

1. push โค้ดขึ้น repository
2. ไปที่ **Settings → Pages**
3. เลือก **Source: Deploy from a branch** แล้วเลือก branch `main` โฟลเดอร์ `/ (root)`
4. รอสักครู่แล้วเข้า `https://<ชื่อผู้ใช้>.github.io/<ชื่อ repo>/`

ไฟล์ `.nojekyll` มีไว้บอก GitHub Pages ว่าไม่ต้องประมวลผลด้วย Jekyll ทุก path ในโปรเจกต์นี้เป็น path แบบสัมพัทธ์อยู่แล้ว จึงวางไว้ใน subfolder ได้โดยไม่ต้องแก้อะไร

## โครงสร้างไฟล์

```
index.html             โครงหน้าเว็บ
styles.css             สไตล์ทั้งหมด
app.js                 ตรรกะเกมและทุกหน้าจอ
manifest.webmanifest   ข้อมูลสำหรับติดตั้งเป็นแอป
sw.js                  service worker สำหรับเล่นออฟไลน์
icon.svg               ไอคอน
icon-maskable.svg      ไอคอนแบบ maskable สำหรับ Android
build.js               รวมทุกอย่างเป็นไฟล์เดียวใน dist/
```

### อยากได้ HTML ไฟล์เดียว

```bash
node build.js
```

จะได้ `dist/index.html` ที่ฝัง CSS และ JS ไว้ในตัว เอาไปแปะที่ไหนก็เปิดได้ทันที ต้องใช้ Node ในขั้นตอนนี้อย่างเดียว ตัวเกมเองไม่ต้องใช้

## แผนที่โค้ดใน `app.js`

ไฟล์เดียวแต่แบ่งเป็นแปดส่วนชัดเจน มีคอมเมนต์หัวข้อคั่นไว้

1. ข้อมูลธีม — ชุดพื้นหลัง ชุดสีช่อง ฟอนต์ ความโค้ง
2. ที่เก็บข้อมูล — โหลดและบันทึกลง localStorage
3. ธีม — แปลงค่าที่เลือกเป็น CSS custom property
4. เช็คอิน — นับวันต่อเนื่อง นับรายเดือน ปลดล็อกของรางวัล
5. เครื่องเกม — ตรรกะการเลื่อนและผสม การวาดกระดาน อินพุต
6. กระดานคะแนน
7. หน้าจอ — สลับหน้าและวาดแต่ละหน้า
8. เริ่มทำงาน

### จุดที่ควรรู้ก่อนแก้

**มุมโค้งมีสี่ระดับ ห้ามบวกลบข้ามระดับ**

`--rc` กล่องใหญ่ · `--ru` ปุ่ม · `--rs` ช่องเล็ก · `--rt` ช่องในเกม

เคยเขียนเป็น `calc(var(--ru) + 7px)` แล้วพัง เพราะโหมดกลมใช้ค่า `999px` บวกไปก็ยังเท่าเดิม กล่องเลยกลายเป็นแคปซูลและข้อความล้นออกนอกส่วนโค้ง ถ้าต้องการมุมใหม่ ให้เพิ่มระดับใน `RADII` ไม่ใช่คำนวณเอาเอง

`--cpad` คือระยะขอบในกล่อง ต้องโตตามมุมโค้งเสมอ หลักคร่าวๆ คือไม่ควรน้อยกว่าราวเจ็ดสิบเปอร์เซ็นต์ของรัศมี

**สีช่อง 2 ถึง 16 ไม่มีค่าตายตัว**

คำนวณจาก `color-mix` ของสีตัวอักษรกับสีพื้นตอนรันไทม์ เพื่อให้ปรับตามพื้นหลังได้เองทุกธีม ชุดสีใน `RAMPS` จึงเริ่มที่ช่อง 32 และมี 9 คู่พอดี (32 ถึง 8192 ขึ้นไป) ถ้าเพิ่มชุดสีใหม่ต้องใส่ให้ครบ 18 ค่า

**ท้าทายประจำวันใช้ตัวสุ่มแบบกำหนดค่าเริ่มต้นได้**

`mulberry32` ที่รับ seed จากวันที่ อย่าเปลี่ยนอัลกอริทึมหรือลำดับการเรียก `G.rng()` ถ้าไม่จำเป็น เพราะจะทำให้กระดานของวันเดียวกันไม่ตรงกับเครื่องอื่น

**แก้ไฟล์แล้วอย่าลืมขยับเวอร์ชันใน `sw.js`**

ตัวแปร `VERSION` ใน `sw.js` คุมชื่อ cache ถ้าไม่ขยับ เครื่องที่เคยเปิดเกมจะยังเห็นเวอร์ชันเก่าจนกว่าจะล้าง cache เอง

## เรื่องการล็อกหน้าจอแนวตั้ง

เว็บบังคับทิศทางหน้าจอไม่ได้จริง โปรเจกต์นี้จึงทำสามชั้น

1. `"orientation": "portrait"` ใน manifest ซึ่งได้ผลจริงเมื่อติดตั้งเป็นแอปบน Android
2. เรียก `screen.orientation.lock()` เผื่อเบราว์เซอร์ที่รองรับ
3. หน้ากั้นด้วย CSS ที่ขึ้นมาบังเมื่อจอเป็นแนวนอนและสูงไม่เกิน 620px ซึ่งเป็นชั้นที่ทำงานจริงบนมือถือส่วนใหญ่

เงื่อนไขข้อสามจงใจไม่บังคอมพิวเตอร์ที่หน้าต่างเป็นแนวนอนตามธรรมชาติอยู่แล้ว

**iOS Safari ไม่รองรับการล็อกหน้าจอเลยไม่ว่าเงื่อนไขใด** บน iPhone จะเหลือแค่หน้ากั้นตามข้อสาม

## กระดานคะแนน

โค้ดรองรับสองแบบและสลับให้เองตามสภาพแวดล้อม

- **เปิดจากเว็บทั่วไปหรือ GitHub Pages** จะแสดงคะแนนสูงสุดของเครื่องตัวเอง เก็บใน localStorage
- **เปิดในฐานะ artifact บน claude.ai** จะต่อเข้ากับที่เก็บข้อมูลของแพลตฟอร์มและแชร์คะแนนกันได้ในกลุ่มผู้ใช้เดียวกัน

ถ้าต้องการกระดานคะแนนที่ใช้ได้จริงบนเว็บสาธารณะ ต้องมี backend เอง จุดที่ต้องแก้อยู่ในหัวข้อที่ 6 ของ `app.js` ฟังก์ชัน `initCloud`, `watchBoard` และ `submitScore` ออกแบบไว้ให้สลับไปใช้บริการอื่นอย่าง Firebase หรือ Supabase ได้โดยไม่ต้องแตะส่วนอื่น

## ข้อมูลผู้เล่น

ทุกอย่างเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น ภายใต้คีย์เดียวคือ `g2048.profile.v1` ไม่มีการส่งข้อมูลออกนอกเครื่อง ไม่มี analytics ไม่มี tracking

ล้างข้อมูลทั้งหมดได้จากในเกมที่หน้าตั้งค่า
